# Hero media

Four short clips from GDC's existing project reels, used as the full-width home-page background. Swift uses seconds 5–17 of its original; Midnight East uses seconds 40–52, showing the illuminated entrance and evening event; ARIEL uses seconds 14–26, showing the stage, screen, branded launch reveal, and venue; NSSF uses seconds 24–36, showing the completed conference stage, screens, lighting, and room layout. Each plays silently and is 12 seconds, 1280×720, 24 fps, H.264, with no audio track and MP4 fast-start metadata. Matching JPEG posters are captured at 0.5 seconds of the clip.

| Clip | Original GDC reel |
| --- | --- |
| `nssf.mp4` | [10th NSSF Annual General Meeting](https://gdc-ltd.org/assets/projects%20media/NSSF%202026%20AGM/NSSF%20SET%20UP%202026%20compresed.mp4) |
| `midnight-east.mp4` | [Midnight East Nairobi](https://gdc-ltd.org/assets/projects%20media/MIDNIGHT%20EAST%20EVENT/Midnight%20east%20set%20up%20reel(GDC).mp4) |
| `ariel.mp4` | [ARIEL Product Launch](https://gdc-ltd.org/assets/projects%20media/Arial/Arial%20GDC%20reel.mp4) |
| `swift.mp4` | [Swift Connect Africa 2024](https://gdc-ltd.org/assets/projects%20media/Swift/SWIFT.mp4) |

The table follows playback order. NSSF is the initial video and poster; Swift plays last before the rotation returns to NSSF.

To change a selection, replace its clip and matching poster or update `heroVideos` in `content/site.json`, then run `node scripts/build.mjs`. Keep background clips short and silent, and supply a poster for every selection.

These are the initial hero selections for design review. Full case-study videos continue to use the original remote reels.
