# Hero media

Three short clips from GDC's existing project reels, used as the full-width home-page background. The clips contain seconds 5–17 of each original and play silently. Each is 12 seconds, 1280×720, 24 fps, H.264, with no audio track and MP4 fast-start metadata. Matching JPEG posters are captured at 0.5 seconds of the clip.

| Clip | Original GDC reel |
| --- | --- |
| `swift.mp4` | [Swift Connect Africa 2024](https://gdc-ltd.org/assets/projects%20media/Swift/SWIFT.mp4) |
| `iea.mp4` | [IEA Global Conference](https://gdc-ltd.org/assets/projects%20media/IEA/IEA%20GDC.mp4) |
| `un-sacco.mp4` | [UN SACCO Jubilee Celebration](https://gdc-ltd.org/assets/projects%20media/UN%20SACCO/UN%20Sacco%20reel.mp4) |

To change a selection, replace its clip and matching poster or update `heroVideos` in `content/site.json`, then run `node scripts/build.mjs`. Keep background clips short and silent, and supply a poster for every selection.

These are the initial hero selections for design review. Full case-study videos continue to use the original remote reels.
