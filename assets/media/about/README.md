# About imagery

Optimised WebP copies of existing GDC project photos, used in the home-page About section:

- `crew.webp`: `assets/media/projects/issa/cover.jpg`, showing the production crew at the ISSA Technical Seminar. 1200×800, about 122 KB.
- `production-console.jpg`: optimised from the client file `About us small space.jpg`, showing GDC's audio desk at an event. Used as the small inset photo.

The earlier `celebration.webp` remains available but is no longer used in the About section.

The originals remain in the project galleries. Layout crops are set in `styles.css`; these files preserve each source's full image.
